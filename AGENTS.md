# Project layout

- `AGENTS.md` contains project instructions.
- `spec.md` describes the app requirements.
- `prompts.md` stores prompts used while working on the project.
- `index.html` is the single-file web app entry point and must remain at the repository root for GitHub Pages.
- `00_planning/` is for planning notes and sketches.
- `01_data/` is for data files.
- `02_validation/` is for hand calculations and test cases.
- `03_output/` is for screenshots and exported results.

Save each new file in the folder that matches its purpose. Keep the app in the root `index.html`; do not add application files elsewhere.
